# Decode part of the pie vs vLLM gap on B200 (MiniMax's selected attention over a cluster of eight blocks a kv head)

A decode's selected attention ran `sdpa_paged_selected_mma_kernel` a block a (row, kv head): MiniMax-M3's lone decode row is four blocks on a 148-SM B200, each walking a kv head's ~770 selected keys (~390 KB of K and V) through its warps' 16-key chunks, 18.4 us a layer, where vLLM 0.32.0 splits the same blocks 16 ways a head and merges (5.0 + 2.2 us). The kernel now takes `kRanks`: where the fire's (row, kv head) blocks are too few to fill a quarter of the SMs (where it already widened to 16 warps), a cluster of `kernel.sdpa.selected_cluster` blocks of 8 warps reads each (row, kv head), every block a slice of the chunks, and folds the slices' normalized outputs by their log-sum-exps through distributed shared memory, the fold `decode_gqa_sm80.cu`'s clusters use (its `ld_cluster`/`sync_cluster` move to `prim/device.cuh` unchanged); the B200 profile sets 8 (a ranks x warps sweep: 1x16 8.98, 8x4 8.77, 8x8 8.63, 4x8 8.81, 8x16 8.80 ms), the default stays 0, and without a cluster the launch and kernel are as before. MiniMax-M3.1-Flash mini60 (60 layers, 16 of 128 experts) raw decode on B200 8.97 -> 8.62 ms ITL (111.5 -> 116.0 tok/s, 3 alternating rounds each, SM 1965 MHz), the same cut of MiniMax-M3-MXFP8 9.63 -> 9.29 ms (103.8 -> 107.6 tok/s; vLLM 0.32.0 6.92 ms, which can't load M3.1-Flash's NVFP4 experts, nor can 0.33.0 or SGLang 0.5.22), Qwen3.8-Flash-Next mini 0.85 -> 0.82 ms, Qwen3-0.6B 1.03 ms either way with identical tokens; the attention's critical path 18.4 -> 11.8 us a layer.

Greedy tokens on M3-MXFP8 are identical (8/8 x 256); on M3.1-Flash they first differ at token 1-8 on 6/8 requests, at bf16 near-ties (base's top-2 margins 0.0625-1.0 there): teacher-forced over 33 positions, the fix's KL to base (M3.1 0.024-0.149, M3 0.004-0.014 mean) is below that of the scalar selected walk the test holds the tensor-core walk to (0.068-0.253, 0.015-0.021) on every request. `attn::selected` now checks the cluster walk against the scalar walk too (a fold error fails it), `attn::fa2*` pass, the chip test lists the new setting among the B200's own, and the engine-cuda and kernels-cuda GPU suites PENDING.
